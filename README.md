🚗 Fleet Management Console System
=====================================

A C++ console-based Fleet Management System developed as part of my learning journey in Computer Science.

This project demonstrates practical usage of:

1- Structures

2- STL containers (vector, set, map)

3- Nested loops

4- Input validation

5- Basic data filtering and searching

--------------------------------------------------------------



📋 Current Features

The system currently allows the user to:

*Add a new vehicle

*Display all vehicles in the fleet

*Display unique brands in the fleet

*Display vehicle count per brand

*Search vehicles by brand

*Search vehicles by model

*Search vehicles by year

*Exit the program


----------------------------------------------------------------------


🛠 Technologies Used

1- C++

2- Standard Template Library (STL)

3- vector

4- set

5- maps

-------------------------------------------------------------------------------


⚠️ Current Limitations

🔻All logic is currently implemented inside the main() function.

🔻The program follows a procedural structure.

🔻Some operations rely on nested loops, which can be optimized for better performance.

🔻These limitations are intentional at this stage, as the project represents my early implementation before refactoring and restructuring.
